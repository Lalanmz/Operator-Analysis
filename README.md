# 📊 ICTA Power BI Dashboard – Telecom Operator Insights

## Overview
This Power BI dashboard provides a comprehensive analysis of **telecom operators** based on customer survey data. It highlights operator performance, customer satisfaction, and internet service quality to support **data-driven decision-making** and **competitive benchmarking**.

## Key Insights
- 📈 **Market Share**: Distribution of customers across major operators.  
- 🌐 **Internet Quality Index**: Stability, speed, and package sufficiency evaluated per operator.  
- 😀 **Customer Satisfaction**: Key drivers such as price, service quality, and peer influence.  
- 🔄 **Churn Analysis**: Reasons for switching and retention risks.  

## Dashboard Structure
1. **Executive Summary** – High-level KPIs and operator comparison.  
2. **Internet Quality** – Performance and benchmark analysis.  
3. **Customer Satisfaction** – Loyalty, preferences, and service evaluation.  
4. **Churn Insights** – Risk factors and switching behavior.  

## Tools & Technologies
- Power BI Desktop (2023+)  
- Power Query for ETL  
- DAX for KPIs and measures
